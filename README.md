# الجنيه أولاً 🇸🇩 — إصدار البيانات الحقيقية

هذه النسخة تستبدل بيانات العرض المصطنعة ببيانات منشورة في تقرير رسمي لبنك السودان المركزي:

**Economic & Financial Statistics Review — January–June 2026, Issue 2/2026.**

## الملفات
- `app.py`: لوحة Streamlit.
- `trade_monthly_2026.csv`: الصادرات والواردات الشهرية من يناير إلى يونيو 2026.
- `inflation_monthly_2024_2026.csv`: التضخم الشهري من يناير 2024 إلى يونيو 2026.
- `commodity_exports_quarterly_2026.csv`: صادرات الذهب والزراعة حسب الربع في 2026.
- `exchange_rate_snapshots.csv`: نقاط سعر الصرف المرجح المنشورة في يونيو 2025 ومارس ويونيو 2026.
- `requirements.txt`: المكتبات.

## ملاحظات منهجية مهمة
1. بيانات التجارة في CSV مأخوذة من جدول ملخص التجارة الخارجية. 2026 تغطي يناير–يونيو فقط وليست سنة كاملة.
2. التضخم هو معدل التضخم المنشور في جدول الرقم القياسي لأسعار المستهلك. لا تخلطي بين معدل التضخم الشهري/السنوي وبين تغير مؤشر الأسعار.
3. صادرات الذهب والزراعة في ملف السلع ربع سنوية. قيمة الزراعة هي مجموع البنود الزراعية الظاهرة بالتقرير: القطن، الصمغ العربي، الفول السوداني، السمسم، الذرة، بذور البطيخ، الأعلاف، المنتجات الزراعية الأخرى، والزيوت النباتية والحيوانية.
4. سعر الصرف في الملف نقاط مختارة للمتوسط المرجح لسعر شراء الدولار لدى المصارف التجارية والصرافات، كما ورد في الملخص الاقتصادي. لا يمثل سعر السوق الموازي.
5. لا توجد هنا بيانات احتياطيات أجنبية شهرية كاملة؛ لذلك لم نضع أرقاماً تقديرية لها.
6. بعض أرقام 2026 أولية حسب التقرير. يجب تحديثها عند صدور مراجعات لاحقة.
7. لا يمكن استنتاج سبب انهيار العملة أو بناء توقع موثوق لسعرها من هذه المؤشرات القليلة وحدها. نحتاج لاحقاً إلى بيانات عرض النقود، تمويل الحكومة، ميزان المدفوعات، الاحتياطيات، والتحويلات.

## التشغيل
```bash
pip install -r requirements.txt
streamlit run app.py
```

## النشر
ارفع كل الملفات إلى مستودع GitHub، ثم في Streamlit Community Cloud اختر المستودع وملف `app.py`.
